# D++ (D-Plus-Plus) Runtime Engine

An open-source, declarative domain-specific language (DSL) interpreter designed to decouple operational safety policy from low-level execution machinery across cyber-physical and DevOps environments.


##  Quick Start
1. Clone the repo
2. Run the simulation engine:
   ```bash
   python dpp_engine.py farm.dpp
   python dpp_engine.py production.dpp
